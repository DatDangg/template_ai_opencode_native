> ⚠️ **File này do Design Agent sinh/cập nhật ở Phase 2.5** (`AGENT.md` → Phase 2.5 Design).
> Đây là placeholder của template — thay bằng token thật của project.
> Code theme phải import từ `theme/`, **không hardcode** màu/khoảng cách.

## Cách dùng

- Phase 2.5: Design Agent phân tích reference (ảnh/Figma) hoặc style đã chọn ở brainstorm → ghi tokens vào đây.
- Builder/Reviewer đọc file này để style theo token; review UI phải đối chiếu token + device size (small ~360–390, large ~414–430).
- Xem thêm `conventions.md` + `patterns.md` trong cùng thư mục.

## Sections cần có

- **Colors** — brand, surfaces, text, border, semantic (error/success/warning), gradient nếu có.
- **Spacing** — scale thống nhất (vd 4/8/12/16/24...).
- **Radius** — bo góc theo component.
- **Typography** — font family, size, weight, line-height.
- **Elevation** — shadow/elevation levels.
- **Motion / haptics** — duration, easing, haptic feedback.
- **Contrast + anti-patterns** — quy tắc tương phản, điều cấm khi style.
